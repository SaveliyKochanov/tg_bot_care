# Бот заботы


Представляем вам Telegram-помощника для HR-специалистов компании "КрасИнтегра". :sunglasses: :thumbsup:

## Установка
Для установки бота необходимо скачать ZIP-архив проекта или выполнить команду ниже в нужной директории:

```
git clone https://github.com/SaveliyKochanov/tg_bot_care.git
```

Далее в папке проекта необходимо установить библиотеки из файла ***requirements.txt***.

```
pip install -r requirements.txt
```
Если все библиотеки корректно установились, то можно приступать к запуску бота.

## Запуск
Запускайте файл ***main.py*** и создайте чат с ботом

Ссылка на бота -> **@hr_helper_krasintegra_bot**

Наслаждайтесь! :dizzy:
